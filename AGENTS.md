# MethylGrammarLab Website Agent Notes

This repository is a software development project maintained under Ben's AgentOS. It is the Jekyll/GitHub Pages lab website for `methylgrammarlab.org`.

Global Agent OS startup is handled by harness-level or system-level instructions. Agents unfamiliar with Ben's AgentOS conventions should read `prompts/README.md` before modifying this repository.

## Project Context Routing

- Read `prompts/architecture.md` before architecture, dependency, interface, file-format, collection, build, deployment, or major behavior changes.
- Read `prompts/plans.md` before continuing implementation, validation, maintenance work, or resuming a prior task.
- Treat `prompts/*_deep_records_*.md` files as archival. Do not read them during routine development unless Ben explicitly asks for historical/deep-record context or an active context file points to one for a current question.
- Added, renamed, or deleted prompt files must be reflected both here and in `prompts/README.md`.

## Prompt Index

- `prompts/README.md`: Prompt-directory purpose, file roles, and update rules.
- `prompts/architecture.md`: Current project architecture, dependencies, content model, and build/deployment notes.
- `prompts/plans.md`: Current implementation state, validation notes, maintenance guidance, and safe-resume context.
